# HARIZ.MY

Static personal website for Hariz Manaf, prepared for GitHub Pages.

## Publish

1. Create or select the GitHub repository that will host the site.
2. Push these files to the repository's default branch.
3. In **Settings → Pages**, select **Deploy from a branch**, then choose the default branch and `/ (root)`.
4. In **Settings → Pages → Custom domain**, enter `hariz.my` and enable HTTPS after DNS verification succeeds.

The included `CNAME` file preserves the custom domain on deployment.
